# TrumpInvestitions — База знаний

> Инвестиционная торговая платформа, разработанная в рамках учебного проекта ИТМО.

#overview

## Что это за проект

Полнофункциональная симуляция брокерской платформы: пользователь регистрируется, пополняет счёт, торгует акциями и криптовалютой по синтетическим рыночным данным, видит своё портфолио и P&L в реальном времени.

## Архитектура одним взглядом

| Сервис | Язык | Порт | Роль |
|---|---|---|---|
| [[auth-gateway]] | Kotlin / Ktor | 8080 | Единая точка входа, JWT, прокси |
| [[market-data-service]] | Go | 8081 | Котировки, свечи, стакан заявок |
| [[portfolio-service]] | Go | 8082 | Портфель, позиции, P&L |
| [[trading-service]] | Go | 8083 | Ордера, сделки |
| [[pricing_engine]] | C | — | Генератор синтетических данных |

Инфраструктура: [[PostgreSQL]] · [[ClickHouse]] · [[Kafka]] · [[Jaeger]]

## Карта базы знаний

```
00 - Главная       ← вы здесь

04 - Потоки данных ← sequence-диаграммы ключевых сценариев
05 - Разработка    ← локальный запуск, тесты, env vars
```

- **Деплой:** Docker Compose
