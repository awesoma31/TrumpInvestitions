# Переменные окружения

#dev #configuration #env

Полный список всех переменных по сервисам. Значения по умолчанию соответствуют `docker-compose.yml`.

## auth-gateway

| Переменная | Дефолт | Описание |
|---|---|---|
| `DB_URL` | `jdbc:postgresql://postgres:5432/auth_gateway` | JDBC строка подключения |
| `DB_USER` | `auth` | Пользователь PostgreSQL |
| `DB_PASSWORD` | `auth_pass` | Пароль PostgreSQL |
| `JWT_SECRET` | `supersecret` | Секрет подписи JWT ⚠️ |
| `JWT_ISSUER` | `trump-invest` | Issuer в JWT claims |
| `JWT_ACCESS_TTL` | `3600` | TTL access-токена (секунды) |
| `JWT_REFRESH_TTL` | `604800` | TTL refresh-токена (секунды) |
| `MARKET_DATA_URL` | `http://market-data-service:8081` | URL market-data |
| `PORTFOLIO_URL` | `http://portfolio-service:8082` | URL portfolio |
| `TRADING_URL` | `http://trading-service:8083` | URL trading |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | `http://jaeger:4317` | Jaeger OTLP endpoint |
| `OTEL_SERVICE_NAME` | `auth-gateway` | Имя сервиса в трейсах |

## Инфраструктура (docker-compose)

| Переменная | Значение | Сервис |
|---|---|---|
| `POSTGRES_USER` | `postgres` | PostgreSQL superuser |
| `POSTGRES_PASSWORD` | `postgres_pass` | PostgreSQL superuser pwd |
| `CLICKHOUSE_USER` | `market_data` | ClickHouse user |
| `CLICKHOUSE_PASSWORD` | `market_pass` | ClickHouse pwd |
| `KAFKA_BOOTSTRAP_SERVERS` | `kafka:9092` | Внутренний адрес Kafka |

> [!warning] Секреты в продакшене
> Переменные `JWT_SECRET`, `DB_PASSWORD`, `CLICKHOUSE_PASSWORD` в продакшене **никогда** не должны совпадать с дефолтами из docker-compose. Используйте Docker Secrets или Vault.
