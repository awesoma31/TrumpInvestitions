# Локальный запуск

#dev #docker #setup

## Требования

| Инструмент | Минимальная версия |
|---|---|
| Docker | 24.0+ |
| Docker Compose | 2.20+ |
| Go | 1.25 (для разработки без Docker) |
| JDK | 21 (для auth-gateway без Docker) |
| Make | любая |

## Быстрый старт

```bash
# Поднять всё одной командой
make setup

# Проверить статус
make status
```

`make setup` выполняет:
1. Сборку всех Docker-образов
2. Запуск инфраструктуры (PostgreSQL, ClickHouse, Kafka, Jaeger)
3. Применение миграций БД
4. Загрузку тестовых данных через [[pricing_engine]]
5. Запуск всех сервисов

## Команды Makefile

| Команда | Описание |
|---|---|
| `make setup` | Первоначальная настройка и запуск |
| `make up` | Запустить сервисы (без пересборки) |
| `make down` | Остановить все контейнеры |
| `make status` | Статус всех сервисов |
| `make telemetry` | Открыть [[Jaeger]] UI в браузере |
| `make test-unit` | Юнит-тесты |
| `make test-integration` | Интеграционные тесты |
| `make test-gateway` | Тесты gateway |
| `make test-all` | Все тесты |

## Быстрая проверка через curl

```bash
# 1. Регистрация
curl -X POST http://localhost:8080/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"test@test.com","password":"Password123"}'

# 2. Логин (сохранить access_token)
TOKEN=$(curl -s -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@test.com","password":"Password123"}' \
  | jq -r '.access_token')

# 3. Котировки
curl http://localhost:8080/api/v1/market/quotes?symbols=AAPL \
  -H "Authorization: Bearer $TOKEN"

# 4. Пополнить счёт
curl -X POST http://localhost:8080/api/v1/portfolio/balance/deposit \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"amount":"10000.00","currency":"USD"}'

# 5. Купить AAPL
curl -X POST http://localhost:8080/api/v1/trading/orders \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"symbol":"AAPL","side":"BUY","type":"MARKET","quantity":"10"}'

# 6. Посмотреть портфель
curl http://localhost:8080/api/v1/portfolio/portfolio \
  -H "Authorization: Bearer $TOKEN"
```
