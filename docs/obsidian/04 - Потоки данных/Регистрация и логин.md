# Регистрация и логин

#flow #auth #sequence

## Регистрация

```mermaid
sequenceDiagram
    actor C as 📱 Client
    participant AG as auth-gateway
    participant PG as PostgreSQL (auth)

    C->>AG: POST /api/v1/auth/register<br/>{email, password}
    AG->>AG: Валидация email + пароля
    AG->>PG: SELECT * FROM users WHERE email = ?
    PG-->>AG: (пусто)
    AG->>AG: BCrypt hash(password)
    AG->>PG: INSERT INTO users (id, email, password_hash)
    PG-->>AG: OK
    AG->>AG: Генерация access_token + refresh_token (JWT)
    AG->>PG: INSERT INTO refresh_tokens (user_id, token_hash, expires_at)
    PG-->>AG: OK
    AG-->>C: 201 {user_id, access_token, refresh_token, expires_in}
```

## Логин

```mermaid
sequenceDiagram
    actor C as 📱 Client
    participant AG as auth-gateway
    participant PG as PostgreSQL (auth)

    C->>AG: POST /api/v1/auth/login<br/>{email, password}
    AG->>PG: SELECT * FROM users WHERE email = ?
    PG-->>AG: {id, email, password_hash}
    AG->>AG: BCrypt verify(password, hash)
    alt Пароль верный
        AG->>AG: Генерация новой пары токенов
        AG->>PG: INSERT INTO refresh_tokens ...
        AG-->>C: 200 {access_token, refresh_token, expires_in}
    else Пароль неверный
        AG-->>C: 401 Unauthorized
    end
```

## Обновление токена

```mermaid
sequenceDiagram
    actor C as 📱 Client
    participant AG as auth-gateway
    participant PG as PostgreSQL (auth)

    C->>AG: POST /api/v1/auth/refresh<br/>{refresh_token}
    AG->>PG: SELECT * FROM refresh_tokens WHERE token_hash = ?
    alt Токен валиден и не истёк
        AG->>PG: UPDATE refresh_tokens SET revoked = true
        AG->>AG: Генерация новой пары токенов
        AG->>PG: INSERT INTO refresh_tokens (новый)
        AG-->>C: 200 {access_token, refresh_token}
    else Токен не найден или истёк
        AG-->>C: 401 Unauthorized
    end
```

## Авторизованный запрос к бизнес-сервису

```mermaid
sequenceDiagram
    actor C as 📱 Client
    participant AG as auth-gateway
    participant SVC as Любой сервис

    C->>AG: GET /api/v1/portfolio/portfolio<br/>Authorization: Bearer eyJ...
    AG->>AG: Валидация JWT (подпись + expiry)
    alt JWT валиден
        AG->>AG: Извлечь userId из claims
        AG->>SVC: GET /api/v1/portfolio<br/>X-User-Id: <userId>
        SVC-->>AG: 200 {portfolio data}
        AG-->>C: 200 {portfolio data}
    else JWT невалиден / истёк
        AG-->>C: 401 Unauthorized
    end
```
